# LocalDevices

Small Python desktop app for locating Tuya devices on the same local network.

## Setup

```bash
python -m pip install -r requirements.txt
```

Use a Python installation that includes Tk support, since the app opens a desktop window.

## Run

```bash
python localdevices.py
```

Click **Scan local network** to look for Tuya devices that are reachable on your LAN.
